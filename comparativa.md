# Seccion 2: Licencia y Modales
## RA1 · CE: identifica los diferentes tipos de licencia de los sistemas ERP-CRM.
El Software Libre (FSF) se basa en principios éticos y en la libertad que tiene el usuario para ejecutar, analizar, modificar y redistribuir el programa. Por otro lado, el Código Abierto (OSI) aborda este mismo concepto de apertura, pero desde una perspectiva práctica, argumentando que tener acceso al código fuente es una mejor manera de desarrollar tecnología. En contraste, el Software Propietario mantiene el código oculto y bajo el control exclusivo de la compañía o creador.

Ser libre no significa que sea gratuito. La libertad se refiere a los derechos relacionados con el código (libertad de expresión), no al precio que se paga (cerveza gratis). Es completamente legítimo cobrar por vender, empaquetar, alojar o proporcionar soporte a un programa libre.

El Copyleft es una cláusula legal que requiere que cualquier versión modificada de un software libre conserve las mismas libertades al ser redistribuida. Dado que la GPL tradicional solo obligaba a compartir los cambios si se proporcionaba un archivo ejecutable, se creó la licencia AGPL para la nube: esta licencia exige liberar el código modificado a cualquier usuario que interactúe con el programa a través de una red o servicio SaaS.

En el modelo de negocio actual, la edición Community es la versión básica, accesible y gratuita, sostenida por la ayuda de los usuarios. La edición Enterprise es la versión comercial de pago que toma como base aquella y le añade módulos cerrados dirigidos a grandes organizaciones (como autenticación corporativa, auditorías de seguridad y soporte técnico prioritario).
